# 📦 Reson8 Web Client v7.7.1 Release Notes

The full post-launch **Improvements Round**, consolidated into a single release: ten items (IR1–IR10) found from real usage of v7.0.0, covering NSFW confirmation/badge consistency, custom emoji reactions, icon polish, voice sound-alert routing, in-app branding, the mobile attachment picker, and a README rewrite. See [`app-planning/08-improvements-round.md`](../08-improvements-round.md) for the full PRD and [`app-planning/progress.txt`](../progress.txt) for the task-by-task build log.

## 🐛 Bug Fixes

- **NSFW confirmation now prompts on every entry, from every path** (IR1) — previously it only fired once per channel per session, and only when entering via the channel tree (never from the Chats tab).
- **The "18+" NSFW badge is now consistent everywhere a channel name is shown** (IR2) — it now shows in the Chats tab too (the flat open/unread channel list, the mobile chat header, and the desktop tabs strip), not just the channel tree.
- **Custom emoji reactions now render as images, not literal `:name:` text** (IR3) — matching how custom emoji already rendered correctly inside message body text.
- **The "add reaction" and "insert emoji" buttons now both use a smiley-face icon**, matching the desktop client (IR4) — replacing a confusing `+` icon and a literal 🙂 character that risked reading as "send this exact emoji."
- **Joining a voice channel now plays only the "joining channel" sound** (IR5) — it previously also fired "user joined your channel" for yourself, a cue meant only for other occupants.
- **Settings → Application → Disconnect now plays the "disconnected" sound instead of "leaving channel"** (IR6).
- **Leaving a voice channel now reliably plays "leaving channel,"** guarded so it only fires for a real voice-channel leave instead of unconditionally on every cleanup path (IR7).
- **The Reson8 logo now appears in the top bar**, next to the app name (IR8) — previously the app had no visible branding anywhere in the UI itself.
- **The mobile chat attachment picker no longer forces the camera open** (IR9) — it now presents the native chooser, which includes browsing existing photos/files.

## 📋 Documentation changes

The Planning Documents section now points at `app-planning/08-improvements-round.md` (current scope) and `app-planning/archive/v7.0.0-phase-prds/` (historical Phase 1–7 set), replacing the stale links to the now-archived top-level PRD paths.

This closes the Improvements Round — all ten items (IR1–IR10) are complete.
