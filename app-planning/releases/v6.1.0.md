# 📦 Reson8 Web Client v6.1.0 Release Notes

A small out-of-band bug-fix release, ahead of Phase 7's own device-testing pass: three real-device-reported bugs, fixed and verified against the actual `reson8` server's source before Phase 7 continues.

## 🐛 Bug Fixes

- Fixed the Channels tab sometimes showing no channels at all right after connecting, for any user — a timing race where the app started listening for the server's channel-tree update one step too late, so on some connections that update arrived before anything was listening for it and was silently missed.
- Fixed a false "Insufficient Permissions" alert (toast + sound) that fired for every non-admin user on every single connect, even though they hadn't tried to do anything — an internal permission check the app runs automatically in the background was being reported to the user as if it were a blocked action.
- Fixed the Voice tab in the bottom navigation, which still showed a "Coming in Phase 2" placeholder — it now shows the real, fully-functional voice panel (occupant list, mute/deafen/leave, mic level) that's been working elsewhere in the app since Phase 2.
