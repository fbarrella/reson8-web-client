# 📦 Reson8 Web Client v1.0.0 Release Notes

Phase 1 complete: the project is scaffolded end-to-end and the first vertical slice works — connect to a real Reson8 server, see the live channel tree with presence, and reach the always-available Settings surface, across mobile, tablet, and desktop layouts.

## ✨ New Features & Improvements

- Project scaffold: Vite + React 19 + TypeScript (strict), ESLint flat config, Prettier, Vitest + React Testing Library, Playwright (multi-browser + mobile emulation).
- Vendored Reson8 wire-protocol types (`src/types/reson8-protocol/`), snapshotted from the desktop repo with source/commit tracking.
- Design system: single dark theme via Tailwind v4 CSS tokens, shadcn/ui-style primitives (Button, Input, Label, Badge; Radix Dialog/Tabs/Toast/DropdownMenu/Popover/Slider/Avatar installed for later phases).
- Mobile-first responsive app shell: single-column nav-stack on mobile (bottom tab bar), collapsible drawer on tablet, fixed three-pane composition on desktop — one component set, three breakpoints.
- Typed Socket.io connection layer and Zustand connection store, with automatic reconnection (including a proper re-join handshake, not just a bare transport reconnect).
- Connect screen: server URL / nickname / password, Remember Me (persisted under the desktop client's exact localStorage key names), inline error states that distinguish "can't reach that server" from "incorrect password."
- Persistent, login-free instance identity (`crypto.randomUUID()`), with a Copy Instance ID button on the About tab.
- Read-only channel tree render: collapsible categories, text/voice channel rows, live presence (mute/deafen/away), NSFW badges, unread-dot placeholders.
- Color-coded latency indicator with NTP-style clock-offset measurement, ready for Phase 2's voice session timers.
- Settings shell with all 7 desktop tabs stubbed; About and Application (mute alerts) fully functional this phase.
- Sound alert infrastructure with the desktop client's real asset set, gated correctly behind the browser's autoplay-unlock gesture.
- Generic toast system for error/status reporting across the app.
- PWA baseline: installable manifest + service worker (`generateSW` mode), Lighthouse-installable build output.

## 🐛 Bug Fixes

- Fixed a dead hamburger-menu button on mobile (visible but its target drawer only rendered at the tablet breakpoint).
- Fixed insufficient color contrast on the NSFW "18+" badge (3.17:1 → passes WCAG's 4.5:1 for small text).
- Added the missing page-level heading once a user leaves the connect screen (axe-core `page-has-heading-one`).
- Fixed reconnection after a server-side restart: the client now re-sends `USER_JOIN_SERVER` on Socket.io's `reconnect` event instead of just resuming the ping loop, so channel-tree/presence data actually flows again after an outage.
