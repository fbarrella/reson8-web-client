# 📦 Reson8 Web Client v7.5.0 Release Notes

Fifth and sixth fixes in the post-launch improvements round: voice-related sound alerts now route to the right sound in the right situation.

## 🐛 Bug Fixes

- Settings → Application → Disconnect now plays the "disconnected" sound instead of "leaving channel."
- Leaving a voice channel now reliably plays "leaving channel," guarded so it only fires for a real voice-channel leave instead of unconditionally on every cleanup path.
