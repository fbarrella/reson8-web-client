# 📦 Reson8 Web Client v2.0.0 Release Notes

Phase 2 complete: voice channels are now fully functional — join, talk, mute/deafen, push-to-talk, device selection, and reconnection resilience are all wired up on top of the server's mediasoup SFU.

## ✨ New Features & Improvements

- Client-side mediasoup voice engine (`VoiceService`): Device/Transport/Producer/Consumer lifecycle, framework-agnostic and independently testable, driving the full 6-step handshake (router capabilities → send/recv transports → connect → produce → consume → resume).
- Tap-to-join voice channels from the channel tree, with a joining indicator and permission-denial-aware error handling.
- Explicit microphone permission denial recovery UI, with platform-specific guidance (iOS Safari / Android / Firefox / generic) and a one-tap retry.
- Remote audio playback via DOM-attached `<audio>` elements (not detached `Audio()` instances), for reliable playback including on mobile Safari.
- Mute/Deafen accumulation state machine, ported to match the desktop client's actual shipped behavior: deafening auto-mutes and remembers only if it had to; undeafening restores exactly that prior state; clicking Mute while deafened auto-undeafens first, then applies a toggle on top.
- Push-to-Talk mode (press-and-hold on-screen button for mobile, focused-tab keyboard shortcut for desktop) alongside the default Voice Activation mode, with an independent "locked" mute flag so PTT press/release never conflicts with the Mute button.
- Configurable keyboard shortcuts for PTT/Mute/Deafen/Disconnect, recorded live and persisted per the desktop client's localStorage key conventions.
- Audio input/output device selection in Settings → Voice & Shortcuts, with a staged-then-Saved apply pattern and graceful degradation where `setSinkId` output-device selection isn't supported (Safari/Firefox).
- Active Speaker Indicator: a ring halo on speaking occupants' avatars, in both the channel tree and the voice panel.
- Flicker-free voice session timer (MM:SS), sourced from the server's session start time and clamped to never show a negative duration.
- Reconnection resilience across four independent failure modes: WebRTC transport loss (with a 4s grace period before treating "disconnected" as failed), Socket.io-level reconnects (full voice rejoin, not just a resumed ping loop), server-reported mediasoup worker crashes (`VOICE_SESSION_LOST`), and mobile tabs silently losing their connection while backgrounded (Page Visibility API trigger).
- Voice mini-bar (mobile/tablet, pinned above the tab bar) and full voice panel (persistent desktop third column / mobile-tablet sheet) — one component set, three compositions.
- Voice-specific sound cues (join/leave, mute/unmute, deafen/undeafen, connected, per-event user-joined/left) using the desktop client's asset-key vocabulary.

## 🐛 Bug Fixes

None this phase — all Phase 2 work was new capability, not fixes to prior behavior.
