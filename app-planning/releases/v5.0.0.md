# 📦 Reson8 Web Client v5.0.0 Release Notes

Phase 5 complete: 1-on-1 direct messaging with persistent history, an online-users directory, read receipts, and the Nudge attention-getting feature.

## ✨ New Features & Improvements

- Direct messages: mobile nav-stack full-screen conversation route + desktop tabs strip for multiple simultaneously-open conversations, reusing Phase 4's composer, emoji picker, and reactions components rather than rebuilding them.
- Online Users directory (`GET_ONLINE_USERS`) — includes offline previously-contacted partners, not just currently-connected users; tapping anyone opens or creates a conversation.
- A persistent Direct Messages entry point in the app header, visible at every breakpoint (not just the mobile bottom tab bar), with a live unread-count dot.
- Connect-time unread-DM hydration: desktop opens a tab per unread partner; mobile shows a badge, and auto-navigates straight into the conversation when there's exactly one unread partner waiting.
- Persistent DM history that stays fully readable while a partner is offline, with an online/offline status indicator in the conversation view.
- Delete-only DM messages (no edit — the protocol has none), with the same always-reachable kebab menu pattern as channel messages.
- Live-synced emoji reactions on DM messages, same picker and toggle behavior as channel messages.
- Read receipts: a "Sent"/"Read" label under your last message in a conversation, refreshed opportunistically whenever the partner sends something new while you have the conversation open.
- Nudge: send a one-tap attention-getter to another user, with a 30-second per-pair cooldown enforced server-side (not just a disabled button). Recipients get a toast, a sound cue, a vibration, and an app-icon badge bump when the tab is backgrounded — every device API feature-detected and silently skipped where unsupported. Hidden everywhere the moment a server admin disables Nudge.

## 🐛 Bug Fixes

None this phase — all Phase 5 work was new capability, not fixes to prior behavior.
