# 📦 Reson8 Web Client v6.0.0 Release Notes

Phase 6 complete: full admin & moderation control surface — role management, custom-emoji approval, kick/ban, server-wide settings, and a polished password-protected connect flow, all gated exactly against the server's real permission requirements.

## ✨ New Features & Improvements

- Settings → Roles: view every server user with their current role badges, tap to expand and toggle role assignment. An admin can't remove their own admin-equivalent role via the UI — the toggle is disabled with an explanatory note instead of failing silently server-side.
- Settings → Emojis: a pending custom-emoji review queue with submitter nickname and image preview; Approve makes it instantly usable in every connected client's picker, no reload.
- Settings → Server: a Nudge enabled/disabled toggle (requires literal admin) plus a Banned Users list with one-tap Unban (requires the ban permission specifically — the two sections gate independently).
- Settings tabs (Roles/Emojis/Server) are now permission-gated for real — a non-admin account never sees them, replacing Phase 1's "coming soon" placeholders.
- Kick from a voice channel: an admin-only action in the occupant menu. The kicked user gets a toast and a clean voice-session teardown, and can rejoin immediately — kicking isn't a ban.
- Ban / Unban a user from the Online Users directory, with a confirmation dialog and a note about the instance-ID-based identity model's inherent circumvention vector. A banned user's next connection attempt is rejected with a clear message, and their client is redirected live if they're already connected.
- The password-protected connect flow now distinguishes "this server requires a password" from "you typed the wrong one," instead of one generic connection-failure message.
- A persistent Direct Messages entry point in the desktop header (added while verifying this phase) — Phase 5 had no way to reach DMs on desktop at all.

## 🐛 Bug Fixes

- Fixed a Rules-of-Hooks violation in the Settings sheet that could crash the entire settings panel for an admin account right as their permissions finished resolving after connecting.
