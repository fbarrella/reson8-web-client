# 📦 Reson8 Web Client v7.8.0 Release Notes

Two standalone follow-up fixes after the Improvements Round: the Vercel-hosted app no longer 404s on a subroute reload, and the app finally shows its actual icon.

## 🐛 Bug Fixes

- **Fixed 404 on subroute reload when deployed on Vercel.** Added a `vercel.json` with a catch-all SPA rewrite to `index.html` — Vercel, unlike Netlify/Cloudflare Pages, doesn't auto-detect SPA routing for a plain Vite build, so any client-routed path (`/app`, `/app/dms/:id`, etc.) 404'd on a direct load or reload without this. `DEPLOYMENT.md`'s incorrect claim that Vercel handled this automatically has been corrected.
- **Replaced the wrong app icon** used for the browser-tab favicon, the top-bar logo, and the README header. The correct Reson8 icon (`public/icons/icon-512.png` — the orange circle with an "8" + sound-wave mark, already used correctly for the PWA install icons) is now used everywhere, via two newly generated, properly small derivatives (a 32×32 favicon and a 64×64 logo) instead of the old, incorrect `favicon.svg`, which has been removed.
