# 📦 Reson8 Web Client v4.0.0 Release Notes

Phase 4 complete: full per-channel text chat — send/receive/edit/delete, file attachments with instant feedback, the complete emoji system (curated picker, reactions, custom emoji with a crop tool and approval flow), degraded link previews, and pinned messages.

## ✨ New Features & Improvements

- Per-channel text chat: mobile nav-stack full-screen chat route + desktop tabs strip for multiple simultaneously-open channels, sharing one `<ChatPane>` component.
- Paginated message history with scroll-to-top load-older, scroll position preserved across the prepend, and auto-scroll to new messages only when already near the bottom.
- Composer: auto-growing textarea, Enter-to-send with a mobile-safe explicit Send button, cursor-aware emoji insertion, and instant local thumbnail + progress on file attachment — before the upload request resolves.
- Client-side attachment validation (5MB cap, MIME allowlist) that fails fast with a clear message before any network request fires.
- Edit (2-minute window) and delete of your own messages, via an always-reachable kebab menu with hover-reveal as a progressive enhancement.
- Unread channel indicators that correctly exclude your own messages and only mark a channel unread when you're not actively viewing it.
- Curated ~552-emoji picker (9 categories + search), with the custom-emoji tab kept in a fixed, always-visible slot outside the scrolling category row.
- Emoji reactions — tallied, toggleable, live-synced across clients.
- Custom emoji upload: touch-adapted pan/pinch/zoom crop tool, submission reaches a visibly-pending state in your own picker, and becomes usable app-wide the moment it's approved — no reload required.
- Degraded-scope link previews: bare URLs auto-link everywhere; a small CORS-verified oEmbed allowlist (YouTube, Vimeo, Spotify, SoundCloud) renders an inline preview card with a click-to-expand embed player.
- Pinned messages: pin/unpin/replace with confirmation, a pinned bar with jump-to-pin (including a fetch-a-window fallback for messages outside the loaded page), and live sync — including auto-unpin when a pinned message is deleted.
- Message content (including `:name:` custom-emoji tokens and auto-linked URLs) is rendered entirely via a parsing pass into React elements — never string-concatenated HTML.

## 🐛 Bug Fixes

None this phase — all Phase 4 work was new capability, not fixes to prior behavior.
